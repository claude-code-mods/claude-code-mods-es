# turbo

> Versión en español por el proyecto claude-code-mods-es; el autor original y la licencia figuran al final. El README original está en [README.en.md](README.en.md).

Una fábrica de software de agentes con supervisión humana: tú decides qué construir y juzgas el resultado; las skills se encargan de dar forma, construir, pulir y entregar los cambios, y aprenden de ellos.

## Instalación

```
/plugin install turbo@claude-code-mods-es
```
