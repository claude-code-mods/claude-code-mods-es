# Skins para Claude Code

> Versión en español por el proyecto claude-code-mods-es. El README original en inglés está en [README.en.md](README.en.md).

Pieles para la transcripción de Claude Code: líneas de herramientas con iconos, tarjetas de diff, tablas y diagramas Mermaid, barra de estado de uso y quince temas. `/skin` cambia el tema al instante.

## Instalación

```
/plugin install skins@claude-code-mods-es
```

Tras la instalación, ejecuta `/skin` para elegir el tema.
