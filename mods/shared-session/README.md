# shared-session

> Versión en español por el proyecto claude-code-mods-es. El README original en inglés está en [README.en.md](README.en.md).

Comparte sesiones de Claude Code con un enlace o con tu equipo: los compañeros se unen desde su propio Claude Code y conversan; una sesión hace el trabajo y todos ven cada turno en tiempo real, mientras el host aprueba lo que se ejecuta en su máquina.

## Instalación

```
/plugin install shared-session@claude-code-mods-es
```
