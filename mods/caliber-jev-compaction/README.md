# caliber-jev-compaction

Compresión Jev con preservación literal para sesiones de Claude Code.

## Instalación

```
/plugin install caliber-jev-compaction@claude-code-mods-es
```

Tras instalar, puedes introducir tu propia clave API de TypeSafe en la configuración del complemento.
