# lcu-approve

> Versión en español por el proyecto claude-code-mods-es; el autor original y la licencia figuran al final.

Autorización nativa por aplicación para las operaciones de LCU con el ordenador en la aplicación Claude y en Claude Code (permitir una vez, permitir siempre, denegar), además de un panel de aplicaciones autorizadas para `/computer-use-apps`.

## Instalación

```
/plugin install lcu-approve@claude-code-mods-es
```
