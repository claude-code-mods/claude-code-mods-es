# work-mode

Modos de sesión `/work-mode` para Claude Code:

- `auto`: no hace preguntas a mitad del trabajo.
- `out`: delega trabajo por lotes.
- `wrap`: converge y cierra el trabajo.

También incluye un recordatorio de delegación.

## Instalación

```
/plugin install work-mode@claude-code-mods-es
```
