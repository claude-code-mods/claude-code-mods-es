# Firstmate Calm

> Versión en español por el proyecto claude-code-mods-es; el autor original y la licencia figuran al final.

Firstmate Calm lleva a Claude Code una animación de navegación a vela y una transcripción propia de cada sesión, y comparte las preferencias de calm de cada usuario con la extensión Pi Calm.

Su módulo de hooks puede cargarse mediante `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` o el despliegue gradual tengu_plugin_hooks_modules de Claude Code, pero solo surte efecto cuando `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` es exactamente 1; en cualquier otro caso no hace nada.

## Instalación

```
/plugin install fm@claude-code-mods-es
```
