# TavernWeaveX

> Versión en español por el proyecto claude-code-mods-es. El README original en inglés está en [README.en.md](README.en.md).

23 habilidades compartidas para fichas de personaje, trabajo de software y tareas acotadas en la nube, con comprobación de capacidades y handoff reanudable; inyecta Host Front Door en Claude Code, añade el agent tavernweave y ofrece un interruptor de modo Soul encima del prompt. La ejecución real depende de las herramientas y permisos del host.

## Instalación

```
/plugin install tavernweave-agent-skills@claude-code-mods-es
```
