# multi-core

> Versión en español por el proyecto claude-code-mods-es. El README original en inglés está en [README.en.md](README.en.md).

Usa modelos de ChatGPT (Codex), Cursor, OpenCode Zen y Antigravity en una misma sesión de Claude Code. Cambia con `/model`, delega en workers nativos con nombre y conserva el inicio de sesión y los permisos de cada proveedor.

## Instalación

```
/plugin install multi-core@claude-code-mods-es
```
